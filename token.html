Get your Client ID & Token

Both values are required, and they must come from the same app. This page builds the authorisation link for you and catches the token when Twitch sends you back.

What these two things are

Client ID — a public identifier for an application registered on Twitch. It is not your username, not a password, and not secret. It says "these requests come from this app."

Access token — proves a Twitch account authorised that app to act on its behalf. This one is secret.

They must be a matched pair. A token issued to app A will be rejected if you send it with app B's Client ID. This is the #1 cause of 401 errors — the diagnostics page checks for it explicitly.

Step 1 · Register an application

  1. Go to dev.twitch.tv/console/apps and log in. Two-factor auth must be enabled on your Twitch account, or Twitch won't let you register anything.
  2. Click Register Your Application.
  3. Name: anything unique — e.g. Dungeons & Derailleurs Shoutout. If it says the name is taken, add a word.
  4. OAuth Redirect URL: paste exactly this — it's where Twitch sends the token back.
    This is this page's own address. It must match character for character. If you later serve the overlay from a different address (a different port, or GitHub Pages), come back and add that one too — an app can have several redirect URLs.
  5. Category: Broadcasting Suite.   Client Type: Public.
  6. Click Create, then Manage on your new app. Copy the Client ID.
Ignore the Client Secret. You don't need it, and it should never go into a URL or a browser source. If you accidentally generated one, that's fine — just don't use it.

Step 2 · Authorise and get your token

Authorise on Twitch →
Twitch will ask you to approve the app, then send you straight back here with the token attached. Nothing is transmitted anywhere except to Twitch.

Which route should I take?

Register your own app (above) — recommended. The token is tied to an app you control, and you can re-issue it whenever you like.

Or use a token generator site such as twitchtokengenerator.com — quicker, but there's a catch that trips people up constantly:

If you use a generator site, you must use that site's Client ID, which it displays alongside the token. Your own app's Client ID will not work with their token. Use whichever pair came from the same place.

Token lifespan

Implicit-grant tokens (what this page produces) last around 60 days, but can be invalidated sooner if you change your password or revoke the app.

When it expires the overlay goes blank. Just revisit this page and authorise again — same Client ID, new token. The diagnostics page warns you if your token has under 24 hours left, so check it before a big stream.
