Reference

!so userQueue a shoutout. Multiple shoutouts stack in a queue and play in order.
!watchclip userPlay a clip for anyone — ignores the mods/VIP restriction.
!replaysoReplay the last shoutout. Aliases: !soreplay, !clipreplay, !replayclip
!stopclipStop the current clip immediately. Mods/broadcaster only. Aliases: !sostop, !clipstop
!clipreloadReload the browser source. Mods/broadcaster only. Alias: !soreload
You can also fire one from the browser console for testing: shoutout('someuser')

Add a Browser Source and paste the generated URL. Set:

Width × Height1920 × 1080 — then scale the source in your scene, don't change these
Shutdown source when not visible✓ on — stops audio playing on hidden scenes
Refresh browser when scene becomes active✓ on — reconnects chat reliably
Control audio via OBS✓ on — clip audio becomes a normal mixer channel
Clip audio needs "Control audio via OBS" ticked or you won't hear it. If clips are silent on your stream but audible locally, that's the setting.

Generate a token with these scopes (an implicit-grant token is fine):

(none)Profile, clips, category, live status, account age — all work with just a valid token
moderator:read:followersFollower counts. Only returns data for channels you moderate — otherwise the stat is hidden automatically
user:write:chatOnly if you enable "post shoutout message in chat"
Follower counts are restricted by Twitch. The API only returns them for channels you moderate. For everyone else these layouts hide the stat rather than show a zero — this is a Twitch policy limit, not a bug.

4 · Behaviour

A delay lets your own raid alert play first.
In OBS the browser source is transparent by default, so Transparent lets your gameplay show through around the overlay. Pick Solid only if the shoutout is its own full scene.
Fit gives the clip its own window in the space the text panels do not use, so nothing is drawn over the video and none of the picture is cropped. Full screen is the old behaviour: the clip fills the frame and the panels overlap it.
Set this to match the Width/Height you give the OBS Browser Source. Text is enlarged to stay readable, and the least useful details are hidden at the smallest sizes.
Prefer clips from the last N days. Falls back to all-time if none found.

4b · Custom images — optional

Relative path or full URL. Bake AI images to transparent PNGs first: python tools/bake-asset.py raw.png --out assets/emblem.png — see docs/AI-ASSETS.md.
Generate artwork once and ship it. Calling an image API at shoutout time would add 3–20s of delay, cost per shoutout, and put an API key in your browser-source URL.
