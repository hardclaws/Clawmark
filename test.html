Manual test checklist

  1. Diagnostics green — run the checks above first.
  2. Preview in the builder — open index.html, click through layouts.
  3. Overlay in a normal browser tab — paste your generated URL, add &test=someuser&debug=1. A shoutout should fire on load. Open DevTools console for logs.
  4. Chat command in a browser tab — with the overlay open, type !so someuser in your channel's chat. It should play.
  5. Queue — fire three !so commands quickly. They should play one after another, not overlap.
  6. Mod commands — !stopclip mid-clip should cut it; !replayso should replay the last one.
  7. Into OBS — add the Browser Source with the four settings from the README. Confirm you can hear the clip (needs "Control audio via OBS").
  8. Edge cases — shout out a brand-new channel with no clips (should show the profile card), and a name that doesn't exist (should fail silently, not hang).
